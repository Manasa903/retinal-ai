Our Aim

The aim of this project is to develop an intelligent, deep learning–based clinical decision support system for automated retinal disease classification using OCT images. By leveraging a ResNet50 model enhanced with CBAM attention mechanisms, the system accurately identifies multiple retinal conditions, estimates prediction confidence, detects unknown or unseen diseases, and provides meaningful clinical recommendations. This project aims to support ophthalmologists with faster, reliable, and interpretable AI-assisted diagnosis, improving early detection and aiding informed medical decision-making.
